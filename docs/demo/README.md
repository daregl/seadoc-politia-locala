# Pachet demo SeaDoc

Deschide `index.html` într-un browser. Conține starea demo-ului, arhitectura, scenariul de 12 pași și fiecare pagină din aplicație.

- `ecrane/`: capturile, desktop și telefon (`t-*`).
- `arhitectura.svg`: diagrama pentru pasul 1.
- `BRIEF-agent-chrome.md`: instrucțiuni pentru o verificare de citire în Chrome.

Datele din capturi sunt fictive. Pachetul nu conține parole. Conturile sunt pe server, în `.data/demo-credentials.txt`.
